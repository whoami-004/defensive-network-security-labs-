# Defensive Network Security Labs

By Chandru Ganesan

This repository contains hands-on defensive cybersecurity labs focused on network monitoring, traffic analysis, and intrusion detection.

## Tools Covered

- Snort
- Wireshark
- Tcpdump

## Topics

- Packet Capture and Analysis
- Network Traffic Monitoring
- Intrusion Detection
- Threat Investigation
- Security Event Analysis

These labs were completed as part of my cybersecurity learning journey and demonstrate practical experience with defensive security tools used in real-world environments.
